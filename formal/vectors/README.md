# Fixed-window refinement vectors

`rate_limiter_traces.json` is generated in Vultrino's Rust test suite by the
same pure `fixed_window_transition` called by the production `Instant` adapter.
The test compares the generated bytes with the committed fixture. Govder keeps
an exact byte-for-byte copy and pins the same SHA-256:

```text
ab102718048eb7fd40d045daf1e5b1c0ab355361e0b5a7352e4cd7ed0f8b86ec
```

The cases are tight witnesses for a cold zero-duration interval, a lag shorter
than a window, an exact whole-window lag, and a two-window lag. Tick resolution
exists only to place a reachable carried allowance immediately before a
boundary; production decides the same predicate with `Instant` and `Duration`.
